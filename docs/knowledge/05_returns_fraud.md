# Returns & Fraud Exception Policy (SAMPLE)

> **Sample policy for NEXUS RAG demos.**

## Returns
Return rate alerts when category return value > 8% of revenue for the month.

## Fraud / cancel flags
Orders marked `is_fraud` or high cancel clusters by payment type require case review before refund release.

## Perfect order
Perfect order = OTIF + no cancel/fraud + complete delivery. Use as executive quality KPI alongside OTIF.
